# Takt — design studies

Відкрий `index.html` у браузері. Усі шрифти й ресурси локальні, збірка та мережа не потрібні.

Або запусти локальний сервер:

```sh
python -m http.server 8765 --bind 127.0.0.1 --directory /home/kpyr/Projects/Takt/design-explorations/2026-09-22
```

Адреса: http://127.0.0.1:8765

- `index.html`, `styles.css`, `app.js` — інтерактивна галерея A / B / C.
- `RESEARCH.md` — оцінка поточного UI, офіційні джерела, аргументація та межі концепції.
- `QA.md` — проведені перевірки.
- `previews/` — знімки реального HTML-рендеру.
- `assets/` — локальні шрифти Inter, Noto Serif та їхні ліцензії.
- `research/` — витяги офіційних джерел через Scrapling.

Усі показані дані демонстраційні. Додавання та редагування працюють у пам'яті сторінки до оновлення. Це концепції для вибору, не перенесений Android UI.
