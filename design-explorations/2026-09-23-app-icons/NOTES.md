# Takt: п’ять напрямів іконки

Лише вибір дизайну. AndroidManifest, ресурси launcher icon і код застосунку не змінено.

Генерація: `codexlb-imagegen`, Images API через налаштований CodexLB, запитаний `gpt-image-2`, quality high, окремий запит на кожен варіант. Повні промпти: [prompts.json](prompts.json).

Оригінальні відповіді API збережено як `01-takt.png` … `05-step.png`. Сервіс повернув RGBA 1254×1254 з артефактами навколо символів. У файлах `*-preview.png` нормалізовано масштаб, прибрано дрібний шум/матові краї та додано рівний кобальтовий фон; силуети походять зі згенерованих зображень.

[five-directions.png](five-directions.png) — порівняння п’яти концепцій. Фіолетові версії вручну скомпоновано з тих самих силуетів як попередній показ монохромного перефарбування; це не перевірка реального Android launcher.

Після вибору: точно відтворити обраний силует у придатному для Android форматі, додати adaptive icon foreground/background і окремий monochrome drawable. Тематичні іконки використовуватимуть кольори системної палітри на Android 13+ у лаунчерах із відповідною підтримкою. Окремо перевірити круглу/заокруглену маску й малий розмір.
