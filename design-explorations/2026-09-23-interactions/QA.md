# Takt — меню, жести та пропуски, 2026-09-23

Змінено код у поточній `feature/pulse-design`, попередні незакомічені зміни збережено. Нічого не опубліковано; версію застосунку не змінено. Перевірено на окремому headless API35 емуляторі `emulator-5580`, не на фізичному телефоні.

## Поведінка

- Налаштування предмета: шторка у поточній темі, окремий рядок іконки, кнопки статусів, радіовибір оцінювання, результат pass/fail та редактор шкали збережені.
- Вікно іконок: фіксований Dialog з кнопкою закриття, сітка займає решту висоти. Відсутній draggable/nested-scroll батько; вертикальні свайпи й крайові overscroll жести не закривають вікно.
- Час у Home та тижневому списку центрований по вертикалі. Прибрано 18dp зовнішнього нижнього відступу Calendar; область прокрутки закінчується безпосередньо біля навігації.
- Кореневі розділи: парні горизонтальні переходи 300ms. Збережено замовлений раніше напрямок: свайп вправо → наступний розділ, вліво → попередній; без зациклення.
- Home, день, тижневий список/сітка та місяць: коротке натискання відкриває пов’язаний предмет, стандартне довге натискання — спільне меню дій. Для події без courseId коротке натискання відкриває її дії, оскільки предмет не прив’язаний.
- Календар зберігає вибраний день, тиждень, місяць і режим при поверненні з предмета.
- Пропуск — окрема позначка відвідування, не скасування. Ключ: id події + початкова дата конкретного заняття + ознака разової події. Перенесення не втрачає позначку, наступний тиждень її не успадковує. Є додавання/зняття, відображення в розкладі, backup/import.

## Діагностика під час роботи

Перший запуск емулятора мав SystemUI startup ANR (`com.android.systemui`, до UI-тестів); системний процес перезапущено через його діалог. Знімки з цим діалогом замінено чистими фінальними. Не виявлено ANR процесу Takt.

Проміжні UI-тести потребували виправлень самого тесту: тижневий список додає тип пари перед назвою (використано substring matcher); прямий activity back dispatcher оминав діалог; shell Back одразу після закриття Dialog був залежний від часу видалення системного вікна. Фінальний сценарій використовує реальні кнопки «Назад»/«Закрити». Журнали невдалих перевірок збережено в evidence; вони не представлені як успішні.

Скріншоти захоплено після завершення переходів. Це знімки емулятора з тестовими даними; вигляд системних панелей залежить від пристрою.
