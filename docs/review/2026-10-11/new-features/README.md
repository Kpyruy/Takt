# Оновлення додатка й незалежні стани оцінювання

## Поведінка

- Після входу в Takt автоматично перевіряється останній стабільний реліз `Kpyruy/Takt` на GitHub. Успішна перевірка кешується на 24 години; мережеві помилки й обмеження GitHub мають паузу перед автоматичною повторною спробою, яка зберігається між запусками.
- У **Налаштування → Оновлення додатка** є встановлена версія, останній знайдений реліз, час перевірки, ручна перевірка та перемикач автоматичних перевірок. Ручна перевірка працює і з вимкненою автоматичною.
- Нові релізи показують пропозицію оновитися. «Пізніше» приховує повторні автоматичні пропозиції для цієї версії; оновлення залишається доступним у налаштуваннях. APK або сторінка релізу відкриваються у браузері для подальшого завантаження й установлення користувачем.
- Публічні запити GitHub використовують окремий клієнт без авторизації та cookies UIS. Перевіряються стабільна версія, HTTPS, репозиторій і відповідність посилання тегу. За відсутності коректного APK відкривається сторінка релізу.
- У формі оцінювання **«Бали входять у підсумкову оцінку»** незалежне від **«Потрібно для допуску»** й мінімуму. Вимкнені бали не входять ані в зароблені, ані в максимум, ані в прогноз потрібних балів на екзамені. Мінімум для допуску продовжує перевірятися.
- **«Роботу здано, очікую оцінку»** прибирає прострочення для написаної роботи. Невідомий результат не перетворюється на підтверджений нуль. Якщо є мінімум балів, допуск не підтверджується до отримання результату; вимога лише здати роботу може виконуватися без оцінки.
- На картках збережено іконки, дату, тривалість і теги. Редактор дати екзамену дозволяє пов'язати будь-який результат екзамену, зокрема виключений із підсумкових балів.

## Збереження даних

Room 17 → 18 додає два поля з попередніми значеннями за замовчуванням: бали враховуються, очікування оцінки вимкнене. Формат резервної копії 9 зберігає обидва поля; старі копії отримують ті самі сумісні значення. Налаштування перевірки оновлень зберігаються окремо від навчальних даних.

## Перевірки

- 221 unit-тест пройшов без помилок: версії, клієнт GitHub, кеш, скасування, повторні запити, незалежність допуску й балів, очікування оцінки та наявні регресії.
- Повний прогін 50 сценаріїв на Android API 35 пройшов: імпорт і міграції, резервні копії, відновлення чернеток, вибір семестру, форми, навігація та нові функції.
- Після незалежного рев’ю повторно пройшли 4 сценарії нових функцій, включно з додатковою регресією пов'язування виключеного екзамену. До виправлення ця перевірка відтворювала відсутній результат у виборі; після виправлення зв'язок зберігається.
- Debug APK, тестовий APK і lint зібрані успішно. Lint: 0 errors, 15 warnings, 1 hint.
- Публічний GitHub API перевірено: останній реліз `v0.2.0`, APK `Takt-v0.2.0.apk`. Пропозиція `v0.3.0` використовується лише як симуляція у тестах.
- Новий реліз не створювався, версія додатка не змінювалася. Реальний акаунт UIS і телефон не використовувалися.
